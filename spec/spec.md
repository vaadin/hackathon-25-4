Security status portal for Vaadin users. A customer asks "is my Vaadin version safe, and what do I do?" by typing a version, pasting one or more CVE ids, or uploading a scanner report (osv-scanner, OWASP Dependency-Check, bomber or CycloneDX JSON), and gets a verdict with the exact upgrade that clears the findings. A home page shows every maintained Vaadin line at a glance with its state, newest release and scan date, plus the recently reviewed advisories. An internal area for the security team adds a detailed explorer of every measured release filtered by the products an application actually uses, a Spring Boot findings page, and a verdict workbench where the team composes assessments ranked by how much each verdict would close. All data comes from the JSON the vaadin/cve-status pipeline already publishes on GitHub Pages; the server fetches and caches it, there is no database of its own. An AI assistant answers questions like "is 24.9.21 safe" or "what does CVE-2025-1234 mean for me" using tools over the same data.
